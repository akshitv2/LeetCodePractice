| Name                                           | Description / Example                                                                                                                                                                                                                                   |
|------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 0-1 Knapsack                                   | Given \(N\) items with weights \(w_i\) and values \(v_i\), and a maximum weight \(W\), determine the maximum \(\sum_{i=1}^{k} v_i\) for each subset of items of size \(k\) (\(1 \le k \le N\)) while ensuring \(\sum_{i=1}^{k} w_i \le W\).             |
| Subset Sum                                     | Given \(N\) integers and a target \(T\), determine whether there exists a subset of the given set whose elements sum up to \(T\).                                                                                                                       |
| Longest Increasing Subsequence (LIS)           | Given an array containing \(N\) integers, determine the Longest Increasing Subsequence (LIS), i.e., a subsequence where every element is larger than the previous one.                                                                                  |
| Counting Paths in a 2D Array                   | Given \(N\) and \(M\), count all possible distinct paths from \((1,1)\) to \((N,M)\), where each step is either from \((i,j)\) to \((i+1,j)\) or \((i,j+1)\).                                                                                           |
| Longest Common Subsequence (LCS)               | Given strings \(s\) and \(t\), find the length of the longest string that is a subsequence of both \(s\) and \(t\).                                                                                                                                     |
| Longest Path in a Directed Acyclic Graph (DAG) | Find the longest path in a Directed Acyclic Graph (DAG).                                                                                                                                                                                                |
| Longest Palindromic Subsequence (LPS)          | Find the Longest Palindromic Subsequence (LPS) of a given string.                                                                                                                                                                                       |
| Rod Cutting                                    | Given a rod of length \(n\) units and an integer array `cuts` where `cuts[i]` denotes a position at which a cut must be performed, determine the minimum total cost of performing all cuts. The cost of one cut equals the length of the rod being cut. |
| Edit Distance                                  | The edit distance between two strings is the minimum number of operations required to transform one string into the other. Allowed operations are: **Add**, **Remove**, and **Replace**.                                                                |
